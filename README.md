# Практическая работа №2 — вариант 30
## Этап 1. Минимальный прототип и параметры CLI

На этом этапе реализован только разбор параметров командной строки и проверка их значений.

Поддерживаются:
- `--package <имя>` — обязательное имя npm-пакета;
- `--repository <URL>` — адрес Registry;
- `--version <версия>` — версия пакета (по умолчанию latest);
- `--output <файл>` — имя файла результата;
- `--max-depth <N>` — максимальная глубина;
- `--test-mode` и `--help`.

Проверяются неизвестные и повторные параметры, отсутствие значений, имя пакета, URL и числовая глубина.

## Запуск
```bash
npm start -- --package express
npm start -- --help
```

На этапе 1 сбор зависимостей, построение графа и тесты ещё не добавляются.
